# Docker Setup

## Requirements

- Docker Desktop
- `.env` file with your API keys
- `.gcp-saved-tokens.json`
- `mcp_client/notion_oauth.json`

## 1. Build & Start

Run this from the `agent-harness/` directory (where `docker-compose.yml` lives):

```bash
docker compose up --build
```

This builds the image and starts all services defined in `docker-compose.yml`.

## 2. Attach to the Agent

Once the containers are running, open a new terminal and attach to the agent's interactive session:

```bash
docker attach agent-harness-agent-1
```

> **Note:** `agent-harness-agent-1` is the default container name generated by Docker Compose. If your container has a different name, run `docker ps` to find it.

## 3. Check MCPs

On startup, you should see:

```text
[MCP] Connected to tavily
[MCP] Connected to notion
[MCP] Connected to email
[MCP] Connected to google_calendar
```

## 4. Use the Agent

Once you see the `You:` prompt, enter a request normally.

Example:

```text
You: Use Google Calendar and tell me what I have scheduled this month.
```

## 5. Stop

Press:

```text
Ctrl+C
```

The container is removed automatically, while your workspace and OAuth data remain on your computer.

## Rebuild After Code Changes

If you change the application code, simply re-run:

```bash
docker compose up --build
```

Then attach again in a new terminal:

```bash
docker attach agent-harness-agent-1
```

## End-to-End Scenario

To test the complete agent, try a request that uses the scheduler, memory, local tools, and all MCP integrations:

```text
You: Find the latest information about AI agents on the web, check my Notion for my AI project notes, check my Google Calendar for related meetings this month, and then email me a short summary of your findings.
```

This scenario can exercise:

- **Task Scheduler** — breaks the request into multiple tasks
- **Tavily MCP** — searches the web
- **Notion MCP** — searches project notes
- **Google Calendar MCP** — checks calendar events
- **Email MCP** — sends the final summary
- **On-prem tools** — used by the agent where needed for local files/memory
- **Long-term Memory** — retrieves relevant stored information to help with the request

A successful run should show the agent planning/decomposing the task and connecting to the required MCP tools before producing the final result.
